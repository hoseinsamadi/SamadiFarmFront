# Samadi Farm Front — Next.js

نسخه‌ی مهاجرت‌داده‌شده‌ی رابط کاربری صمدی فارم از Vite/React به Next.js.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## مسیرها

- `/`
- `/products`
- `/story`
- `/reviews`

این branch فقط برای مهاجرت Frontend است و Django/PostgreSQL در آن اضافه نشده است.
